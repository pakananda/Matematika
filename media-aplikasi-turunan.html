Ingat Materi Sebelumnya!

  • Naik Kurva bergerak naik ketika gradien garis singgung positif (f′(x) > 0).
  • Turun Kurva bergerak turun ketika gradien garis singgung negatif (f′(x) < 0).

Apa yang Terjadi di Titik Peralihan?

Saat kurva berhenti naik dan berbalik arah menjadi turun, garis singgungnya mendatar (f′(x) = 0). Titik ini disebut Titik Stasioner.

Pembuktian Matematis Menggunakan Turunan (LKPD 2)

Mengapa ukuran potongan pojok paling optimal adalah tepat 5 cm?

1. Model Fungsi Volume

V(x) = (30 − 2x)(30 − 2x)x
V(x) = 4x³ − 120x² + 900x
Domain fisik: 0 < x < 15

2. Syarat Stasioner V′(x) = 0

V′(x) = 12x² − 240x + 900 = 0
12(x − 5)(x − 15) = 0
Diperoleh x = 5 cm (memenuhi)

3. Volume Maksimum

Alas = 20 cm × 20 cm, Tinggi = 5 cm
V(5) = 20 × 20 × 5 = 2.000 cm³
Uji turunan: (+) di x < 5 ke (−) di x > 5

Input Data Kotak Kelompok

Syarat fisik karton 30×30 cm: nilai x harus antara 0 dan 15 cm.
