Sub-Materi 1

Persamaan Garis Singgung pada Kurva

Garis singgung pada kurva merupakan garis lurus yang menyentuh kurva tepat pada satu titik dan memiliki kemiringan (gradien) yang sama dengan kurva pada titik tersebut.

$m=f'(x)$
1

Gradien Garis Singgung ($m$)

Jika garis tangen mendekati titik $P(x_1, f(x_1))$, gradiennya $m$ didefinisikan sebagai limit perubahan garis sekan saat $h \rightarrow 0$, yang nilainya setara dengan **turunan pertama** fungsi di titik tersebut.

$$m = \lim_{h \rightarrow 0} \frac{f(x_1 + h) - f(x_1)}{h} = f'(x_1)$$
2

Rumus Persamaan Garis Singgung

Dengan mengetahui gradien $m = f'(a)$ dan titik singgung $P(a, b)$ di mana $b = f(a)$, persamaan garis singgungnya dapat ditentukan dengan rumus dasar garis lurus:

$$(y - b) = m(x - a) \quad \text{atau} \quad (y - y_1) = f'(x_1)(x - x_1)$$

Simulation: Garis Singgung Kurva Parabola

Geser posisi titik $x_1$ untuk melihat bagaimana gradien $m = f'(x_1)$ dan persamaan garis singgung berubah secara dinamis.

Fungsi: $f(x) = x^2 - 2x - 1$
Grafik $y = x^2 - 2x - 1$
Koordinat Titik $P(x_1, y_1)$: (1.0, -2.0)
Turunan $f'(x) = 2x - 2$: $f'(1.0)$
Gradien ($m$): 0.0

Persamaan Garis Singgung

$y = 0x - 2$

Contoh Soal 2.8 (Buku Teks PDF)

Tentukan persamaan garis singgung pada kurva $y = 2 - 4x^2$ di titik $(1, -2)$.

Alternatif Penyelesaian:

1. Turunan fungsi: $f'(x) = -8x$

2. Gradien di titik $(1,-2)$: $m = f'(1) = -8(1) = -8$

3. Persamaan garis singgung:

$(y - y_1) = m(x - x_1)$

$(y - (-2)) = -8(x - 1)$

$y + 2 = -8x + 8 \implies \mathbf{y = -8x + 6}$

Sub-Materi 2

Fungsi Naik, Fungsi Turun, dan Fungsi Diam

Kemonotonan grafik suatu fungsi dapat diperiksa melalui tanda positif/negatif dari turunan pertamanya $f'(x)$ pada interval tertentu.

$f'(x)\gtrless0$

1. Fungsi Naik

Grafik bergerak ke atas saat $x$ bergerak ke kanan.

$f'(x) > 0 \quad \forall x \in I$

$x_1 < x_2 \implies f(x_1) < f(x_2)$

2. Fungsi Turun

Grafik bergerak ke bawah saat $x$ bergerak ke kanan.

$f'(x) < 0 \quad \forall x \in I$

$x_1 < x_2 \implies f(x_1) > f(x_2)$

3. Fungsi Diam (Stasioner)

Grafik mendatar, tidak naik dan tidak turun.

$f'(x) = 0 \quad \text{atau t.t.}$

Garis singgung sejajar sumbu-$x$.

Visualisasi Interval Kemonotonan $f(x) = 2x^3 - 9x^2 + 12x + 10$

Cermati perubahan interval naik (hijau) dan turun (merah) sesuai Contoh Soal 2.9.

Naik: $x < 1$ ($f'(x) > 0$)
Turun: $1 < x < 2$ ($f'(x) < 0$)
Naik: $x > 2$ ($f'(x) > 0$)
Sub-Materi 3

Titik Ekstrem & Uji Turunan

Titik ekstrem (stasioner) terjadi saat $f'(c) = 0$. Jenis titik ekstrem (minimum, maksimum, atau belok) ditentukan melalui Uji Turunan Pertama dan Uji Turunan Kedua $f''(c)$.

$f''(x)$

1 Uji Turunan Pertama

Memeriksa perubahan tanda $f'(x)$ di sekitar nilai stasioner $x = c$:

  • Maksimum Relatif: $f'(x)$ berubah tanda dari positif (+) ke negatif (-).
  • Minimum Relatif: $f'(x)$ berubah tanda dari negatif (-) ke positif (+).
  • Titik Belok Horizontal: $f'(x)$ tidak mengalami perubahan tanda di sekitar $c$.

2 Uji Turunan Kedua ($f''(c)$)

Jika $f'(c) = 0$, nilai turunan kedua $f''(c)$ menentukan cekung grafik dan jenis ekstrem:

  • Maksimum Relatif: $f''(c) < 0$ (Kurva cekung ke bawah $\cap$).
  • Minimum Relatif: $f''(c) > 0$ (Kurva cekung ke atas $\cup$).
  • Uji Gagal: Jika $f''(c) = 0$, gunakan Uji Turunan Pertama.

Eksplorasi Titik Maksimum & Minimum: $f(x) = \frac{1}{3}x^3 - x^2 - 3x + 2$

Visualisasi Uji Turunan Kedua berdasarkan Contoh Soal 2.13 dari buku teks.

Titik Maksimum: $(-1, 3.67)$

$f'(-1) = 0 \quad \text{dan} \quad f''(-1) = -4 < 0$

Turunan kedua negatif menunjukkan grafik cekung ke bawah di titik puncak ini.

Titik Minimum: $(3, -7)$

$f'(3) = 0 \quad \text{dan} \quad f''(3) = 4 > 0$

Turunan kedua positif menunjukkan grafik cekung ke atas di titik lembah ini.

Soal 1.b (Hal 146) Persamaan Garis Singgung

Tentukan persamaan garis singgung dari kurva $y = 2x^2 - 3x + 5$ pada titik yang berordinat $y = 4$.

Langkah Pembahasan:

1. Substitusi $y = 4$ ke parabola: $2x^2 - 3x + 5 = 4 \implies 2x^2 - 3x + 1 = 0$

2. Pemfaktoran: $(2x - 1)(x - 1) = 0 \implies x_1 = 1$ atau $x_2 = 1/2$.

3. Turunan kurva: $y' = 4x - 3$.

4. Untuk titik $(1, 4)$: $m_1 = 4(1) - 3 = 1 \implies (y - 4) = 1(x - 1) \implies \mathbf{y = x + 3}$.

5. Untuk titik $(1/2, 4)$: $m_2 = 4(1/2) - 3 = -1 \implies (y - 4) = -1(x - 1/2) \implies \mathbf{y = -x + 4.5}$.

Soal 6.a (Hal 146) Fungsi Naik & Turun

Tentukan interval fungsi naik dari fungsi $f(x) = x^3 - 3x^2 - 15$.

Langkah Pembahasan:

1. Turunan pertama: $f'(x) = 3x^2 - 6x = 3x(x - 2)$.

2. Pembuat nol $f'(x) = 0 \implies x = 0$ atau $x = 2$.

3. Syarat fungsi naik $f'(x) > 0 \implies 3x(x - 2) > 0$.

4. Berdasarkan garis bilangan: $\mathbf{x < 0 \text{ atau } x > 2}$.

Soal 11.a (Hal 147) Titik Ekstrem

Tentukan titik balik maksimum dari fungsi $f(x) = x^3 - 6x^2 + 9x + 4$.

Langkah Pembahasan:

1. $f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3) = 0 \implies x = 1$ atau $x = 3$.

2. Uji Turunan Kedua: $f''(x) = 6x - 12$.

3. Untuk $x = 1 \implies f''(1) = -6 < 0$ (Titik Balik Maksimum).

4. Nilai Maksimum: $f(1) = 1^3 - 6(1)^2 + 9(1) + 4 = 8$.

5. Koordinat Titik Balik Maksimum adalah $\mathbf{(1, 8)}$.
